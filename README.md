# BluetoothChatApp

Bluetooth (RFCOMM) を使ってテキストメッセージを送受信するデスクトップアプリケーションです。

## 必要な環境

- Python 3.9 以上
- Bluetooth 対応の PC（Linux / macOS / Windows）
- Linux の場合は BlueZ がインストールされていること

## インストール

### Poetry を使う場合（推奨）

```bash
poetry install
```

### pip を使う場合

```bash
pip install -r requirements.txt
```

## 起動方法

```bash
python main.py
```

起動すると「Bluetoothファイル送受信」というタイトルのウィンドウが表示されます。

## 使い方

アプリには 3 つの主要な機能があります。

### 1. デバイスの検索

**[検索]** ボタンをクリックすると、周囲の Bluetooth デバイスを検索します。見つかったデバイスのアドレスと名前がコンソール領域に表示されます。

### 2. メッセージの送信

1. 「送信したいアドレス」欄に、送信先の Bluetooth アドレス（例: `XX:XX:XX:XX:XX:XX`）を入力します。
2. 隣のテキスト欄に送信したいメッセージを入力します。
3. **[送信]** ボタンをクリックすると、指定したアドレスへ RFCOMM 経由でメッセージが送信されます。
4. 送信先からの応答がコンソール領域に表示されます。

### 3. メッセージの受信

1. 「受信したいアドレス」欄に、自分の Bluetooth アドレスを入力します。
2. 隣のテキスト欄に使用するチャンネル番号（例: `1`）を入力します。
3. **[受信]** ボタンをクリックすると、指定したチャンネルで接続を待機します。
4. 相手から接続があると、受信したデータがコンソール領域に表示されます。

### 4. 終了

**[終了]** ボタンをクリックするか、ウィンドウを閉じるとアプリが終了します。

## 画面構成

```
┌──────────────────────────────────────────────────────┐
│ Bluetoothアドレスを検索します        [検索]          │
│                                                      │
│ 送信したいアドレス [アドレス] [メッセージ] [送信]    │
│                                                      │
│ 受信したいアドレス [アドレス] [チャンネル] [受信]    │
│                                                      │
│ ┌──────────────────────────────────────────────────┐ │
│ │ コンソール出力                                   │ │
│ │ （検索結果・送受信ログが表示されます）           │ │
│ └──────────────────────────────────────────────────┘ │
│                                                      │
│ [終了]                                               │
└──────────────────────────────────────────────────────┘
```

## 注意事項

- 送受信を行うには、相手側のデバイスもペアリング済みで RFCOMM 接続を受け付ける状態である必要があります。
- 受信モードは一度に 1 件の接続のみ処理します。受信が完了すると待機状態は終了します。
- OS によっては Bluetooth の使用に管理者権限や追加の権限設定が必要な場合があります。

## プロジェクト構成

```
BluetoothChatApp/
├── main.py              # アプリケーションのエントリーポイント（GUI）
├── requirements.txt     # pip 用の依存パッケージ一覧
├── pyproject.toml       # Poetry 用のプロジェクト設定
├── poetry.lock          # 依存パッケージのロックファイル
└── src/
    ├── search.py        # Bluetooth デバイスの検索
    ├── send.py          # RFCOMM 経由のメッセージ送信
    └── receive.py       # RFCOMM 経由のメッセージ受信
```
