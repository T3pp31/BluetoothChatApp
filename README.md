# BluetoothChatApp

Bluetooth (RFCOMM) を使ってテキストメッセージを送受信するデスクトップチャットアプリケーションです。

## 必要な環境

- Python 3.9 以上
- Bluetooth 対応の PC（Linux / macOS / Windows）
- Linux の場合は BlueZ がインストールされていること

## インストール

### Poetry を使う場合（推奨）

```bash
poetry install
```

### pip を使う場合

```bash
pip install -r requirements.txt
```

## 起動方法

```bash
python main.py
```

起動すると「Bluetooth チャット」というタイトルのウィンドウが表示されます。

## 使い方

### 1. デバイスの検索

**[検索]** ボタンをクリックすると、周囲の Bluetooth デバイスをバックグラウンドで検索します。見つかったデバイスがリストに表示されます。

リスト内のデバイスをクリックすると、そのアドレスが「接続先アドレス」欄に自動入力されます。

### 2. 受信の開始

1. 「接続先アドレス」欄に自分の Bluetooth アドレスを入力します（検索結果からクリックで選択も可能）。
2. 「チャンネル」欄にチャンネル番号を入力します（デフォルト: `1`）。
3. **[受信開始]** ボタンをクリックすると、バックグラウンドで接続を待機します。
4. 受信中も GUI は操作可能で、メッセージの送信もできます。
5. 受信を止めるには **[受信停止]** をクリックします。

### 3. メッセージの送信

1. 「接続先アドレス」欄に送信先の Bluetooth アドレスを入力します。
2. メッセージ入力欄にテキストを入力します。
3. **[送信]** ボタンをクリック、または Enter キーを押すとメッセージが送信されます。

### 4. 終了

**[終了]** ボタンをクリックするか、ウィンドウを閉じるとアプリが終了します。

## 注意事項

- 送受信を行うには、相手側のデバイスもペアリング済みで RFCOMM 接続を受け付ける状態である必要があります。
- OS によっては Bluetooth の使用に管理者権限や追加の権限設定が必要な場合があります。

## プロジェクト構成

```
BluetoothChatApp/
├── main.py              # アプリケーションのエントリーポイント（GUI）
├── requirements.txt     # pip 用の依存パッケージ一覧
├── pyproject.toml       # Poetry 用のプロジェクト設定
├── poetry.lock          # 依存パッケージのロックファイル
└── src/
    ├── search.py        # Bluetooth デバイスの検索
    ├── send.py          # RFCOMM 経由のメッセージ送信
    └── receive.py       # RFCOMM 経由のメッセージ受信（連続受信対応）
```
